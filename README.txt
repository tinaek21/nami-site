娜米的彩虹數字學｜網站檔案說明

【資料夾內容】
index.html    網站主頁（所有文字、版面、計算器與互動都在這個檔案裡）
assets/       圖片與影片（必須和 index.html 放在同一層）

【上傳方式】
把「index.html」和整個「assets」資料夾，一起上傳到網站主機的同一個目錄。
例如放在 https://你的網域/nami/ 底下，網址就是 https://你的網域/nami/

免費快速上線：打開 https://app.netlify.com/drop ，把整個「nami-site」資料夾拖進去，約一分鐘就會拿到網址。

【之後要替換的檔案】
assets/nami-video1.mp4        首屏影片（第二、三段為 nami-video2.mp4、nami-video3-v2.mp4；替換時檔名保持一樣即可）
assets/nami-video*-poster.jpg 影片載入前顯示的畫面

【連結】
所有預約諮詢／領報告按鈕都連到 LINE：https://lin.ee/vCed8SL
在 index.html 裡搜尋「lin.ee」就能一次找到全部。

【建議】
上線後可在 </head> 前貼上 Google Analytics 或 Meta Pixel 追蹤碼，追蹤報名轉換。
