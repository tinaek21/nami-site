Game START 派對花絮｜電動激情降低社交尷尬感

2024年02月

按下起始鍵的那一刻，尷尬就先降低了一半。

這場活動由娜米與戀愛小秘書團隊主辦，透過精心安排的電動積分賽與美食，成功打破參與者間的社交隔閡，讓每位與會者度過難忘的派對時光。開場提供披薩、薯條、各式零嘴與冰涼飲料，讓大家在美食陪伴下輕鬆開啟對話。

重點活動為電動遊樂競技賽，場地提供PS5、PSVR2代、Switch、Xbox Series S與PS4等多款主機，電玩積分賽讓大家在競技的激情中迅速拉近彼此距離，透過合作與競技迅速消除陌生感。主持人帶領現場氛圍，介紹場地並進行分組，獲勝者獲得獎盃與難忘回憶。

活動尾聲，不少參與女性已預約下場遊戲時間，現場也預告了下一場「愛情調酒派對」的舉辦資訊，讓意猶未盡的學員能夠繼續期待下一次相遇。
